원하는 시간에 보험사의 계약 정보, 수금 내역, 수수료 데이터를 자동으로 수집하고 GA의 ERP에 연동합니다.

RPA란

RPA는 정해진 규칙과 일정에 따라 반복 업무를 실행하는 자동화 기술입니다. 사람이 매번 처리하던 수집과 변환을 자동화해 컨설턴트와 관리자가 판단이 필요한 업무에 집중할 수 있습니다.

RPA 서버 공용 · 관리자용
  • 데이터 연계에 필요한 계정과 인증 정보(아이디, 비밀번호, 휴대폰, 이메일)를 관리합니다.
  • 데이터 종류별로 수집 일정을 설정합니다.
  • 클라우드 서버의 자료를 조회하고 내려받거나 다시 받을 수 있습니다.
  • 서비스 이용 현황, 작업 이력, 공지사항을 확인합니다.
데이터 서버 GA별 구성
  • 연계 서버에서 지정한 설정에 따라 수집 작업을 수행합니다.
  • 보험사별 원본과 CSV·Excel로 변환한 데이터를 함께 저장합니다.
  • 정보보안을 위해 각 GA가 소유한 고정 IP 서버를 사용합니다.
ERP 연동 GA별 ERP
  • 보험사마다 형식이 다른 원본을 GAIA 등 ERP에서 사용할 수 있는 표준 데이터로 변환합니다.
  • 변환 결과를 ERP에 반영하며, 담당자가 파일을 직접 올려 적용할 수도 있습니다.
추가 인증 및 이메일
  • 휴대폰 문자로 추가 인증을 처리합니다.
  • 이메일로 자료를 요청하고 회신받은 데이터를 자동으로 처리합니다.

RPA 프로세스

보험사별 데이터와 처리 절차를 표준화한 뒤 고객사의 환경에 맞춰 수집, 운영, 구축 방식을 설정합니다.

  • 수집 방식

    클라우드 RPA가 보험사 자료를 자동으로 수집하고 표준 형식으로 변환합니다. 고객사 전용 서버를 사용해 수집 업무의 연속성을 높이고 개인정보 보호 기준에 맞춰 데이터를 관리합니다.

  • 운영 관리

    서버에서 수집 작업을 실행해 장애 위험을 줄입니다. 고객사별 일정과 보조 파일을 설정하고, 알림톡으로 작업 상황을 확인하고 대응할 수 있습니다.

  • 표준 모델과 기능 확장

    공통 모델을 고객사의 업무에 맞게 보완하고 인사, 보증보험 등 연계 기능을 추가하거나 개선합니다.

  • 구축 및 테스트

    표준 모델을 적용하면 구축과 검증에 약 3개월이 걸립니다. 여러 금융사에 구축한 경험을 바탕으로 운영 환경을 검증합니다.
